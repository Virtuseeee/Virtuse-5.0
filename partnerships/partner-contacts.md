# Partner contacts — Buy Bitcoin & Mining

Public contact points for the partners on
[`buy-bitcoin.html`](../Kimi_Agent_Virtuse%20MiCA%20Partners/buy-bitcoin.html)
and [`mining.html`](../Kimi_Agent_Virtuse%20MiCA%20Partners/mining.html),
gathered from each company's own site 2026-09-02 for the
[partner discount outreach](partner-discount-outreach.md). Public,
generic contacts only — none of these were confirmed by actually calling
or emailing anyone, so treat as a starting point, not verified working
inboxes. Company contact pages/staff/emails change — re-check before
relying on this if it's been a while since 2026-09-02.

## Read this before emailing any of them

**You almost certainly already have a better contact than the ones
below.** Every partner in both tables already has a live referral/
affiliate relationship with Virtuse — the tracked referral links already
on `buy-bitcoin.html`/`mining.html` (see that page's source for the
current URLs: 21bitcoin, Kraken, Bybit EU, and Invity on Buy Bitcoin;
OneMiners, Abundant Mines, and Power Mining on Mining). That means each
one has an affiliate dashboard, portal, or account manager already
assigned to Virtuse. A message inside that existing relationship
(affiliate portal message, or whoever originally set up the referral
link) reaches a real person far faster than a cold email to a generic
public inbox — especially at Kraken and Bybit, where `affiliate@`/`press@`
addresses likely queue into a large support system rather than reach
anyone empowered to approve a custom discount. Use the table below only
if you don't already have that contact on file.

## Confidence key

- **Confirmed**: found directly on the company's own official page (not a
  third-party scraper site like Lusha/ZoomInfo/RocketReach, which are
  often stale or wrong).
- **Corroborated**: not directly readable (e.g. Cloudflare-obfuscated),
  but matched independently across two sources.
- **Unverified/low confidence**: only found via third-party databases,
  not confirmed on the company's own site — 21bitcoin is the one case
  of this here.
