Інструменти для розробників Біткоїна

Бібліотеки, SDK, тестові середовища й матеріали для читання для розробників, які будують на Біткоїні та Lightning. Насамперед відкритий код; кілька проєктів підтримують європейські команди.

Як ми обираємо

Кожен запис ми обираємо вручну: він має стосуватися лише Біткоїна, бути актуальним для Європи, працювати та бути чесним. Кожен висновок ми пишемо самі. Платні розміщення завжди позначені «Спонсоровано» і ніколи не змінюють нашого висновку. Наші критерії розміщення.

    A modern Rust library for building on-chain wallets, with bindings for mobile and other languages.

    • Rust
    • Open source
    • Wallet library
    bitcoindevkit.org ↗

  • Lightning Dev Kit (LDK)

    A flexible Lightning implementation as a library, for teams that want Lightning inside their own app.

    • Rust
    • Lightning
    • Open source

  • Breez SDK

    Add self-custodial Lightning payments to an app with a few calls.

    • SDK
    • Lightning

  • Bitcoin Core

    The reference implementation. Its RPC interface and documentation are the base of most Bitcoin software.

    • Reference

    A modular, plugin-friendly Lightning node implementation.

    • C
