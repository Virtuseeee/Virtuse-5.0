Coinbase Institutional

Люксембург (CSSF, MiCA)
Деталі

MiCA CASP-ліцензія через CSSF Люксембургу, паспортизована на всі 27 країн ЄС. Coinbase Prime пропонує кастоді, виконання угод, алгоритмічну торгівлю та фінансування.

  • MiCA у всіх 27 країнах ЄС
  • Зберігання, виконання, торгівля та фінансування
  • Coinbase Prime (кастоді та виконання угод)
  • SOC 2 Type II
Зв'язатися з Coinbase

Sygnum Дискреційний

Швейцарія (FINMA)
Деталі

Швейцарський банк із банківською ліцензією FINMA. Sygnum Select пропонує дискреційні мандати для корпоративних казначейств з активним управлінням, включно з ребалансуванням і хеджуванням.

  • Банківська ліцензія FINMA (а не лише CASP)
  • Дискреційні мандати для казначейства
  • Понад CHF 4 млрд активів під управлінням
  • Активне управління (ребалансування, хеджування)
Зв'язатися з Sygnum

BitGo API

Німеччина (BaFin, MiCA)
Деталі

Інституційний кастодіан з MiCA CASP-ліцензією через BaFin (Німеччина). Зберігання рівня ETP з API для інтеграції у ваші власні системи.

  • MiCA через BaFin (Німеччина)
  • Інституційний кастодіан
  • Зберігання рівня ETP
  • API для інтеграції
Зв'язатися з BitGo

Чи зберігає Virtuse наш Біткоїн?

Ні. Кастоді та виконання угод здійснює обраний вами регульований партнер. Virtuse ніколи не зберігає кошти, ключі чи Біткоїн клієнтів.

Як Біткоїн відображається в обліку компанії та оподатковується?

Це залежить від вашої юрисдикції та стандарту бухгалтерського обліку; уточніть у свого аудитора та податкового консультанта. Наші податкові довідники за країнами підсумовують правила для 13 країн ЄС. Це загальна інформація, а не податкова чи бухгалтерська консультація. Податкові довідники щодо Біткоїна →

Що охоплює воркшоп для ради директорів?

Стратегію казначейства в Біткоїні, систему розподілу активів і управління ризиками, порівняння варіантів регульованого кастоді та шаблони комунікації з акціонерами.
