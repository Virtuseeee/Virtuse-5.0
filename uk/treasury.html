Рішення для казначейства в Біткоїні
для корпорацій

Стратегії казначейства в Біткоїні для європейських компаній, готові до подання раді директорів. Від освітніх воркшопів до регульованого кастоді та виконання угод: ми з'єднуємо вас із найнадійнішими інституційними партнерами в ЄС. Virtuse не здійснює кастоді самостійно.

1

Навчання

Воркшоп для ради директорів зі стратегії казначейства в Біткоїні та системи управління ризиками

Вибір партнера

Оберіть регульованого провайдера кастоді та виконання угод

3

Впровадження

4

Поточне управління

Звітність, ребалансування та управління

Наші інституційні партнери

MiCA-ліцензовані кастодіани та платформи виконання угод для корпоративних казначейств

Coinbase Institutional
Люксембург (CSSF MiCA)

Найбільший регульований кастодіан криптоактивів у світі. MiCA CASP-ліцензія через CSSF Люксембургу, паспортизована на всі 27 країн ЄС. Понад 13 років досвіду роботи. Coinbase Prime пропонує кастоді, виконання угод, алгоритмічну торгівлю та фінансування. Страхове покриття холодного зберігання $320 млн. SOC 2 Type II.

  • MiCA у всіх 27 країнах ЄС
  • Страхове покриття $320 млн
  • Coinbase Prime (кастоді та виконання угод)
  • Понад 100 млн верифікованих користувачів
Зв'язатися з Coinbase
Sygnum
Швейцарія (FINMA)
ДИСКРЕЦІЙНО

Перший у світі регульований банк цифрових активів. Банківська ліцензія FINMA. Sygnum Select пропонує дискреційні мандати для корпоративних казначейств з активами під управлінням $200 млн. Активне управління, включно з ребалансуванням, стейкінгом і хеджуванням. Швейцарський банківський стандарт.

  • Банківська ліцензія FINMA (а не лише CASP)
  • Дискреційні мандати для казначейства
  • Понад CHF 4 млрд активів під управлінням
  • Активне управління (ребалансування, стейкінг, хеджування)
Зв'язатися з Sygnum
BitGo
Німеччина (BaFin MiCA)
API

Провідний інституційний кастодіан з MiCA CASP-ліцензією через BaFin (Німеччина). Страхове покриття $250 млн. Кастоді рівня ETP, що обслуговує Virtune та інших. Найпотужніший API для інтеграції. Вже обслуговує 21bitcoin: перевірена європейська інфраструктура.

  • MiCA через BaFin (Німеччина)
  • Страхове покриття $250 млн
  • Кастоді рівня ETP
  • Найпотужніший API для інтеграції
Зв'язатися з BitGo
