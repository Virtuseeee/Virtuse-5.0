So funktioniert Selbstverwahrung. Vier Schritte vom Karton zur Cold Storage.

Schritt 01

Gerät beim Hersteller kaufen

Bestellen Sie über die Links oben direkt bei Trezor, Blockstream oder Ledger, nicht bei einem Wiederverkäufer auf einem Marktplatz.

Schritt 02

Seed-Phrase aufschreiben

Richten Sie das Gerät offline ein und schreiben Sie die Seed-Phrase auf Papier oder Metall. Geben Sie sie nie in ein Smartphone oder einen Computer ein.

Schritt 03

Kleinen Testbetrag senden

Empfangen Sie einen kleinen Betrag, prüfen Sie die Adresse auf dem Display des Geräts und üben Sie eine Auszahlung, bevor Sie mehr übertragen.

Schritt 04

Optional: Passphrase oder Multi-Sig

Fügen Sie eine Passphrase hinzu oder ein 2-von-3-Multi-Sig mit einem zweiten Gerät. Blockstream Jade unterstützt Multi-Sig nativ.
