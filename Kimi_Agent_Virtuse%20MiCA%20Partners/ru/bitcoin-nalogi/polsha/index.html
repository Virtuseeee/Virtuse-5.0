Налоги на Биткоин в Польше

Обновлено 13.10.2026

Налоги на Биткоин в Польше по состоянию на Q3 2026: единый налог 19% на прирост капитала. Без освобождения по сроку владения. Порядок подачи: ежегодная декларация PIT-38. Обмен криптовалюты на криптовалюту не облагается налогом: налог платится только с продажи за деньги, товары или услуги. Для каждой продажи рассчитайте прибыль в PLN.
