Bitcoin Developer Tools. Libraries and SDKs.

Libraries, SDKs, test environments and reading for developers building on Bitcoin and Lightning. Open-source first, with several projects maintained by European teams.

10 picks · last reviewed 22 October 2026

Our picks. Each with a one-line verdict.

Rust · Open source · Wallet library

Bitcoin Dev Kit (BDK)

A modern Rust library for building on-chain wallets, with bindings for mobile and other languages.

bitcoindevkit.orgWebsite
Rust · Lightning · Open source

Lightning Dev Kit (LDK)

A flexible Lightning implementation as a library, for teams that want Lightning inside their own app.

lightningdevkit.orgWebsite
SDK · Lightning

Breez SDK

Add self-custodial Lightning payments to an app with a few calls.

breez.technologyWebsite
Reference · C++ · Open source

Bitcoin Core

The reference implementation. Its RPC interface and documentation are the base of most Bitcoin software.

bitcoincore.orgWebsite
Lightning · C · Open source

Core Lightning

A modular, plugin-friendly Lightning node implementation.

blockstream.comWebsite
Lightning · France · Open source

ACINQ (Eclair, Phoenix)

The Paris-based team behind the Eclair node and the Lightning tooling that powers Phoenix.

acinq.coWebsite
Testing · Lightning

Polar

Spin up local Lightning test networks in one click. The fastest way to prototype.

lightningpolar.comWebsite
Newsletter · Technical

Bitcoin Optech

The weekly technical newsletter that tracks protocol changes. Required reading for teams shipping Bitcoin software.
